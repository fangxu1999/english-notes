# 📘 My English Notes

个人英语学习笔记静态站点，按学习来源分册整理日常积累的英语表达、句型背诵与口语纠错。

## 📚 笔记分册

- **📺 YouTube 教学视频笔记**（`youtube.html`）：日常沟通、寒暄、职场会议与邮件、餐厅点餐及情绪分级词汇。
- **🦉 Duolingo 习题背诵库**（`duolingo-quiz.html`）：练习过程中的重点句型与语法笔记汇总，供日常复习与背诵。
- **🗣️ Duolingo 视频对话纠错**（`duolingo-talk.html`）：实时口语练习中的常见表达纠错、冠词与单复数用法及地道短语积累。

## ✨ 功能特点

- 纯静态 HTML / CSS / JS，无需构建即可直接在浏览器访问
- 支持按分类标签筛选与中英文关键词实时搜索
- 自动适配系统浅色 / 深色模式（Dark Mode）
